# hackatonLocaliza

MVP do **LocaCoins**, solução do Case 2 (Engajamento digital no app) do Ruptura 2026 / Localiza Assinatura.

Réplica web mobile do app Localiza Assinatura com o sistema de recompensas: dashboard de telemetria com score de direção, missões diárias/semanais/mensais e troca de LocaCoins por cupons de parceiros.

O código está em [`app/`](app/README.md):

```bash
cd app
npm install
npm run dev   # http://localhost:5180
```
